# دليل النشر والربط الكامل لمتجر رِكاز للعطور (REKAZ Parfums)

تهانينا! متجر رِكاز للعطور أصبح الآن مجهزاً بالكامل بهندسة تجارة إلكترونية سريعة (COD Architecture) مع لوحة تحكم أدمن احترافية، ربط مباشر بـ Supabase، وتأكيد فوري للطلبات عبر واتساب المتجر (`+201106385089`).

---

## 1. ربط قاعدة بيانات Supabase المجانية (في أقل من دقيقتين)

1. افتح حسابك على [Supabase](https://supabase.com/) واضغط **New Project**.
2. سمِّ المشروع مثلاً: `rekaz-perfumes` واختر كلمة مرور قوية لقاعدة البيانات.
3. بعد إنشاء المشروع، اضغط من القائمة الجانبية على **SQL Editor**.
4. اضغط على **New Query** وانسخ محتوى ملف `supabase_schema.sql` (المرفق في مجلد المشروع) أو افتح زر `🗄️ كود SQL` في لوحة تحكم الأدمن.
5. الصق الكود واضغط **Run** باللون الأخضر.
   > سيتم إنشاء جدول `orders` وكافة الفهارس وسياسات الأمان (RLS) فوراً.
6. من القائمة الجانبية في Supabase، اذهب إلى:
   - **Project Settings** -> **API**
   - انسخ:
     - **Project URL** (مثل: `https://xxxxxx.supabase.co`)
     - **Project API Keys** -> انسخ مفتاح **`anon` `public`**.
7. افتح لوحة تحكم الأدمن `admin.html` -> اضغط **⚙️ الإعدادات** -> الصق الرابط والمفتاح واضغط **حفظ وتحديث الاتصال**. ستتحول العلامة فوراً إلى: `🟢 متصل بـ Supabase`.

## 2. النشر على Vercel (مجاناً وبدون تعقيد)

### الطريقة الأولى: عبر GitHub (الموصى بها مع التحديث التلقائي)
1. قم بإنشاء مستودع جديد (Repository) على حسابك في GitHub (مثل: `rekaz-store`).
2. ارفع مجلد `REKAZ` بالكامل إلى المستودع.
3. ادخل إلى [Vercel Dashboard](https://vercel.com/) وسجل بحساب GitHub.
4. اضغط **Add New** -> **Project**.
5. اختر مستودع `rekaz-store` واضغط **Import**.
6. في إعدادات المشروع اضغط **Deploy** مباشرة (الملفات مجهزة بـ `vercel.json` ولن تحتاج أي إعدادات إضافية).
7. خلال 30 ثانية سيكون موقعك لايف برابط سريع مثل: `rekaz-store.vercel.app`.

### الطريقة الثانية: السحب والإفلات المباشر (Vercel CLI / Drag & Drop)
- يمكنك أيضاً تثبيت Vercel CLI عبر تشغيل: `npm i -g vercel` ثم كتابة `vercel` داخل مجلد المشروع ورفعه فوراً.

## 3. ربط الدومين المخصص (Custom Domain)

1. بعد النشر على Vercel، ادخل إلى صفحة مشروعك على Vercel.
2. اذهب إلى **Settings** -> **Domains**.
3. اكتب الدومين الخاص بك (مثلاً: `rekazperfumes.com` أو `www.rekazperfumes.com`) واضغط **Add**.
4. سيعطيك Vercel قيم الـ DNS:
   - للـ Root Domain (`rekazperfumes.com`): **A Record** تشير إلى `76.76.21.21`.
   - للـ Subdomain (`www.rekazperfumes.com`): **CNAME Record** تشير إلى `cname.vercel-dns.com`.
5. ادخل لموقع حجز الدومين الخاص بك (Namecheap, GoDaddy, Hostinger...) وأضف الـ Records المذكورة.
6. خلال دقائق سيعمل الدومين مع شهادة أمان SSL (HTTPS) مجانية تلقائياً.
